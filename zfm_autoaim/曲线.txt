 1. 自瞄跑起来（曲线数据在发了）
  2. 调试电脑上开 PlotJuggler：
  plotjuggler
  3. 点左上角 Start → 选 ROS2 数据源 → 在 Topic 列表里勾选：
    - /debug/gimbal_cmd
    - /debug/gimbal_state
    - /debug/target
    - /debug/ekf_residual
  4. 把想看的曲线拖到右侧画布上

  能看到什么

  ┌───────────────────────────────┬──────────────────────────────────────────┐
  │             曲线              │                   含义                   │
  ├───────────────────────────────┼──────────────────────────────────────────┤
  │ gimbal_cmd.data.0             │ 发给云台的 yaw 指令                      │
  ├───────────────────────────────┼──────────────────────────────────────────┤
  │ gimbal_cmd.data.1             │ 发给云台的 pitch 指令                    │
  ├───────────────────────────────┼──────────────────────────────────────────┤
  │ gimbal_cmd.data.5             │ 开火信号（1=开火）                       │
  ├───────────────────────────────┼──────────────────────────────────────────┤
  │ gimbal_state.data.0 vs data.2 │ 实际 yaw vs 目标 yaw（看跟踪误差）       │
  ├───────────────────────────────┼──────────────────────────────────────────┤
  │ target.data.6                 │ EKF 估计的目标偏航角速度                 │
  ├───────────────────────────────┼──────────────────────────────────────────┤
  │ ekf_residual.data.0~3         │ 测量值 vs EKF 预测值的残差（看滤波健康） │
  └───────────────────────────────┴──────────────────────────────────────────┘

  src2 就是靠这个调的 MPC 参数——把 gimbal_yaw（实际）和 plan_yaw（期望）同时画出来，两条线重合越好说明跟踪越准。你的 src1 现在也能这么干了。
