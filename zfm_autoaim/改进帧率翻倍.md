1. 🚀 帧率翻倍：120fps → 240fps

文件： rm_camera_driver/src/hik_camera.cpp

之前： 每帧调用海康 SDK 的 MV_CC_ConvertPixelType 做 Bayer→RGB8 软件转换 → 5.2ms 之后： 用 OpenCV cv::cvtColor（SIMD 加速，零拷贝包装缓冲区）→ 0.27ms

conv 时间从 5.2ms 降到 0.27ms，每帧总耗时从 8ms 降到 4ms，直接翻倍到接近相机极限 249fps。

2. 🔒 修复 TBB 多线程崩溃

文件： armor_detector/src/armor_detector.cpp + armor_detector.hpp

std::execution::par 并行处理多个装甲板时，cv::PCA 内部有全局状态不是线程安全的。加了 std::mutex cv_mutex_ 只保护 correctCorners（PCA 角点修正），其他操作完全并行，不影响帧率。

3. 📊 result_img 显示 FPS

文件： armor_detector_node.cpp + armor_detector_node.hpp

去掉 Latency 显示，改为每秒更新 FPS 显示在图像左上角，并在日志中每秒输出一次。

4. 🎯 颜色采样优化

文件： armor_detector/src/armor_detector.cpp

findLights 里判断红蓝色的循环从遍历轮廓所有像素改为采样 50 个点，减少大轮廓的颜色计算时间。

5. 🔧 串口配置修复

文件： rm_bringup/config/node_params/serial_driver_params.yaml（install 目录）

install 目录的 port_name 是旧的 /tmp/tty_mcu，已同步为 /tmp/ttyACM_mcu，自瞄才能正确连上 PTY 串口
